# H7 (written BEFORE any spike04 run or result; calibration/test numbers not yet seen)

## Hypothesis
Under sensor noise + actuation delay (condition N1), when the classical opponent C1* (re-tuned under N1) is compared with residual RL (re-trained under N1), the RL has a gain that classical tuning cannot reach iff:
  RL's transient-inclusive RMSE is lower than C1*'s by >= 10% (mean over the 50 locked test trajectories, impr = mean(C1*-RL)/mean(C1*)) AND the paired 95% t-CI of (RL - C1*) lies entirely below 0.
Otherwise the verdict is NO.

Background claim being tested: "tuned C1 tied RL in spike03a because the simulator had no sensor noise / latency, so high gain was free". If the claim is right, C1-old (spike03a gains) should degrade and C1-new (re-tuned) should be forced to lower gain; the RL gain could then reappear.

## Pre-registered definitions
- Conditions. N1 = noise + W2 delay (30 ms = 6 control steps, actuator side, same as spike02/03a). N2 = noise only (delay 0). Plant otherwise = W0 (nominal true plant, cap 80 Nm, no friction).
- Noise: i.i.d. Gaussian on measured joint angle, sigma_q. Measured velocity = finite difference of the NOISY measured angles over one control step (so sigma_qd = sqrt(2)*sigma_q/dt, correlated across steps). Reference (qr, qdr, qddr) are noise-free. Every controller (C0, C1-old, C1-new, C1-new+LPF, RL and RL's base) sees exactly the same measured (q, qd) stream, from a noise array seeded per trajectory seed. Metrics (RMSE etc.) use the TRUE state.
- Noise strength: chosen on calibration seeds 1000-1049 ONLY: smallest sigma_q on the grid {1e-4,2e-4,5e-4,1e-3,2e-3,3e-3,5e-3} such that C1-old (spike03a W0 gains, Kp x9.24, Kd x4.43, not retuned) has RMSE >= 1.3x its own no-noise RMSE (same plant) in BOTH clean and dist, in BOTH N2 (vs W0 no-noise) and N1 (vs delay-only no-noise). One sigma used for both conditions.
- Opponents, each tuned/trained separately in each condition: C0 (untouched teacher), C1-old, C1-new (CMA-ES over Kp,Kd scale, same CMA-ES/pop 8/10 generations/box [0.2,100]/objective as spike03a, calibration seeds only), C1-new+LPF (additionally first-order low-pass on the measured q and qd with cutoff tuned jointly, 3 params, 14 generations, box fc in [1,100] Hz), residual PPO (2M steps per seed, 5 seeds, spike02 hyperparameters unchanged, residual bound 16 Nm) with base C0 and with base C1*.
- C1* := whichever of {C1-new, C1-new+LPF} has the lower calibration objective in that condition (the stronger classical). This is the H7 classical comparator and the RL base. (Chosen on calibration only.)
- RL value per trajectory = mean over its 5 PPO seeds (as in spike03a). Seeds individually also reported.
- Cells: (condition in {N1, N2}) x (clean, dist). Primary verdict = N1. Per cell: WIN if criterion above holds. H7 (primary) = YES if both N1 cells are WIN; PARTIAL if exactly one; else NO. N2 is judged the same way and reported as secondary.
- Secondary comparisons reported (not part of the verdict): RL(base C0) vs C1*; RL(base C1*) vs C1-new alone; C1-old vs C0 vs C1-new degradation (tests the premise that noise penalises high gain).

## Secondary metrics reported alongside RMSE (all on test seeds 0-49, locked)
steady-state RMSE (t>0.5 s), settling time (first time after which max-joint true error stays <0.02 rad, clean only), pulse recovery time (dist), torque saturation fraction, torque energy int tau^2 dt; paired differences with 95% CI; three-axis budget (free DoF, simulation steps, wall-clock).

## Warning rule
Any side winning by >50%: first check test set locked, residual bound respected, and that noise acts on the observations of both sides, before reporting.

## Amendment 1 (written after the no-noise N1 calibration line was printed, before any sigma-grid result with noise or any test-set result)
Observed on calibration seeds: with the 30 ms delay and NO noise, C1-old already diverges (calib RMSE 2.03 / 2.09 vs C0 0.0144 / 0.0227), so the "C1-old >= 1.3x its no-noise RMSE" criterion cannot be evaluated in N1 (it is already saturated by the delay). Rule change: sigma_q is chosen by the N2 (noise-only) criterion alone (smallest grid sigma with C1-old >= 1.3x its W0 no-noise RMSE in both clean and dist). The same sigma is used for N1. The N1 criterion is dropped. Everything else unchanged. Side finding to report: the delay alone breaks the spike03a gains.

Conventions
- `CE:Lnn` = line nn of `docs/paper/claims_evidence.md` (the row ID is given too). `CN:xx` = row xx of `docs/canonical_numbers.md`.
- `sNN/table.md:n` = `results/spikeNN/table.md` line n (same short tags as `skeleton.md`; `s15e` = `results/spike15e`). `eq:n` = `docs/paper/stats/equivalence.md` line n. `README:n` = `README.md` line n.
- Table III and Figs. 1-5 are generated by `figures/make_figs.py` straight from `results/` and `equivalence.md`; each parsed line is asserted by keyword in the script (the line numbers are in `SUCCESS`, `TRACK`, `testd()`, `ladder()`, `fig_k4()`).
- Numbers that appear in the abstract are repeated in the body; they are listed once under the abstract and again where the body states them with a different source line.
- Unit-level and structural numbers (section numbers, "8 settings", counts of items) are listed under "Counts".
- No number in the text lacks a source below (coverage checked by script, see end of file). Numbers whose source is a code file rather than a result file are marked CODE.
